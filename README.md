# Job Application Tracker

A full stack Kanban board to track job applications.

🔗 Live: https://job-tracker-snowy-gamma.vercel.app

## Built with
- React + Vite + Tailwind CSS
- Node.js + Express
- PostgreSQL + Prisma ORM
- JWT Authentication
- Drag and drop with @dnd-kit

## Features
- Kanban board with 5 stages
- Add, update, delete job applications
- Drag cards between columns
- User authentication
